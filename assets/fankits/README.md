# ShadowBattle Fan Kit Assets

ShadowBattle keeps each game's visual resources isolated.

```text
assets/fankits/
├─ shadowverse-ccg/
├─ worlds-beyond/
└─ champions-battle/
```

## Official Cygames Fan Kits

`shadowverse-ccg` and `worlds-beyond` are synchronized only from official Cygames Fan Kit pages. Downloaded files remain unmodified; ZIP archives may also be extracted into per-archive directories for direct use by ShadowBattle.

Every UI page that displays these assets must include the notice required by the applicable Cygames Fan Kit terms and the relevant copyright/trademark notice.

Do not mix files between game namespaces. A visual from the original Shadowverse CCG must not silently become a Worlds Beyond or Champion's Battle asset.

## Champion's Battle

No official Champion's Battle Fan Kit has been validated yet. Its directory exists deliberately, but must remain source-audited before assets are added.
