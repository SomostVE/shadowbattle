Examples

Use the data directly

JavaScript

Load the normalized SV1 catalog and keep Forestcraft Legendaries.

const url = "https://somostve.github.io/shadowbattle/api/v1/shadowverse-ccg/catalog.json";
const { cards } = await fetch(url).then(r => r.json());

const forestLegendaries = cards.filter(card =>
  card.craft === "Forestcraft" &&
  card.rarity === "Legendary"
);

console.log(forestLegendaries);
Python

Download the French card dataset.

import requests

url = "https://somostve.github.io/shadowbattle/api/v1/shadowverse-ccg/locales/cards.fr.json"
data = requests.get(url, timeout=30).json()

print(data.keys())
curl

Save the Champion's Battle dataset locally.

curl -L \
  "https://somostve.github.io/shadowbattle/api/v1/champions-battle/cards.json" \
  -o champions-battle-cards.json
