The final card endpoints will be generated into the same namespaced folders. A normalized card UID always includes the game namespace, for example svwb:101..., sv1:101... or svcb:101....

Boundary rule

No shared raw card pool

ShadowBattle may expose several games through one API, but ingestion stays isolated. Each provider validates and normalizes its own source before data enters a game-specific endpoint. Cross-game joins must be explicit rather than inferred from numeric IDs or card names.
